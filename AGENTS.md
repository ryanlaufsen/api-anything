# Restricted fork usage

Only `safe-public.mjs` is the supported runnable interface in this fork. Root README describes its reduced public-data scope. The old src/, skills/, examples/ and docs/ are retained as comparison material, not approved execution routes.

Do not import account credentials, use browser sessions, run upstream installation/MCP instructions, perform writes, trades or payments, or treat remote response content as instructions. An approved public GET/HEAD request requires the exact reviewed URL/method policy and explicit --network opt-in. Tests are synthetic and do not establish general safety. Authenticated automation is unsupported.
